### 方法论沉淀（可复用）
**从混乱素材目录做内容清点的工作流：**
1. 用 stdlib（zipfile + 正则）直接解析 docx/pptx/xmind，**不需要 pip 安装 python-docx/python-pptx**；PDF 用 `pdftotext -layout`。
2. **给无日期的事件定年份靠三条证据链**：① 图片 EXIF `DateTimeOriginal`（`mdls -name kMDItemContentCreationDate` 或直接正则扫 JPEG 字节流里的 `20\d\d:\d\d:\d\d \d\d:\d\d:\d\d`）；② 文档内的报销单/预算表日期与星期几是否对得上（如"3.26 Thursday"可反推年份）；③ 姊妹社团公开博客的交叉印证。
   - ⚠️ 陷阱：批量拷贝的文件 mtime 会统一变成拷贝时间（本次发现多个文件 mtime 都是 2026-04-30 10:3x），**mtime 不可单独作为事件日期依据**，必须配合 EXIF 或文档内容。
3. 读大量图片前先用 `sips -Z 900` 批量降采样到 /tmp，可大幅省 token。
4. 姊妹社团（资源互补、同事件合作方）的官网是补全残缺活动的最高性价比来源——CS Club 的 `dkucs.com/blog` 提供了 MLE / DIC / HackDKU 三场的完整长文。
5. 交付前对全部引用 URL 跑 `curl -s -o /dev/null -w "%{http_code}"` 实测（用户明确要求）。
